The agents call OpenAI straight from this tab with your key. The key is kept in this tab's session storage, sent only to api.openai.com, and gone when you close the tab. A full run uses about 8 calls.

The study used gpt-4o. Any chat model your key can use works, for example gpt-4o-mini for a cheaper run.
