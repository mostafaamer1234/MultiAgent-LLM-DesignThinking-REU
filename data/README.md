# Data

- **`outputs/`** — Default location for generated JSON (market research reports, `business_info.json`, `persona_output.json`, `conversation_history.json`, `hypothesis_analysis.json`, etc.). Safe to add to `.gitignore` if you do not want outputs in version control.
- **`samples/`** — Example inputs: text snippets, PDFs, saved web research blobs, domain notes. Not required at runtime.
